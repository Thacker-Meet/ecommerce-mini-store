# E-Commerce Mini Store

## Project Overview

This is a full-stack E-Commerce Mini Store project built using:

- React.js
- Node.js
- Express.js
- MongoDB Atlas
- MySQL

---

## Features Completed

### Week 1

- React frontend setup using Vite
- Express backend setup
- MongoDB Atlas connection
- MySQL connection
- `/api/ping` endpoint
- Product Mongoose schema
- CRUD product routes
- 12 sample products seeded
- Postman API testing

---

## API Endpoints

### Products

- GET `/api/products`
- GET `/api/products/:id`
- POST `/api/products`
- PUT `/api/products/:id`
- DELETE `/api/products/:id`

---

## Tech Stack

### Frontend
- React.js
- Axios

### Backend
- Node.js
- Express.js
